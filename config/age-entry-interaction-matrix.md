# Age-aware entry interaction matrix

This private review matrix describes the unreleased landing flow. It does not
authorize a deployment or data collection.

| Entry state | Visible next step | Data boundary | Allowed first result |
|---|---|---|---|
| Adult 18+ self-selection | Existing three questions | Selection is memory-only and unverified | Existing Counter/Table mapping |
| Youth 13-17 local calculation | Existing three questions with youth notice | Birth date is calculated then cleared; no storage or transmission | Counter, Library/share template, community Counter, or Figure Studio |
| Under 13 calculation | Guardian-oriented stop | Birth date is immediately cleared; no account/member path | Start-over control only |
| Direct public route | Existing requested resource | No age or identity data requested | Existing route and focus behavior |

## Adult deterministic outcomes

The existing `4 × 3 × 2` matrix remains unchanged:

- Counter: Learn and Share open BITES; Help opens BIGGIES; Explore opens BITS.
- Table: Learn opens the +U Library; Share opens reviewed Crumb guidance; Help
  opens Ambassador Path; Explore opens `/world/`.
- The selected subject provides the optional next Whole Donuts, TNC, or Donuts
  New School direction.

## Youth deterministic outcomes

The same three questions remain available without collecting information.
Counter outcomes remain the existing BITS/BITES/BIGGIES mapping. Table outcomes
keep Learn in the +U Library and Explore in `/world/`; Share begins with the
existing share template in the Library and Help begins at the Community Counter.
The contextual next action remains the shared community table. Payment,
store, member, pass, Dashboard, and Ambassador destinations are blocked for
the in-memory youth session.

## Preview checklist

1. Root shows only the anonymous figure field, hands/jacks visual language,
   age gate, and no expanded ecosystem surfaces.
2. Adult selection reveals Question 1 and all 24 existing outcomes still focus
   their primary action.
3. Youth date input clears after every eligibility attempt; ages 13-17 show
   the youth notice; under 13 shows only the local stop state.
4. Keyboard focus advances to the next required action; reduced-motion styles
   remove transitions; reset returns to the age gate.
5. Every result states the voluntary `Try -> Learn -> Choose a next path`
   principle: a person can skip, change direction, reset, or leave, and no
   optional local presentation state controls essential resources.
